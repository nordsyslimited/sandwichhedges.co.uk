## Needs-review

**5 items** (down from 7 last audit — 2 WCA callout gaps resolved since 2026-09-06).

### 1. data-howto-cat: box-blight-treatment.html

`data-howto-cat="species"` only. Box blight is a fungal disease, not a species-care topic — the card belongs alongside the other pest/disease articles (box tree moth, honey fungus, aphids) which are all tagged `"pests"`. Recommend adding `"pests"` to give `data-howto-cat="species,pests"`.

### 2. data-howto-cat: formal-vs-informal-hedge.html

`data-howto-cat="species,planting"` is a weak fit. The article is a style-and-format comparison (clipped vs informal), not primarily about choosing a species or planting. No existing category covers it cleanly; if a "comparison" tab is ever added, this is the test case. For now the card is reachable under All — noting for when the filter taxonomy is reviewed.

### 3. data-howto-cat vs tag-text mismatch: pruning-an-overgrown-shrub-or-bush.html

`data-howto-cat="diy"` but the rendered tag text is `"Comparison"`. These are inconsistent: a visitor clicking the DIY tab will see this card (correct) but the tag label tells them it is something else. Either align the tag text to "DIY" or add a comparison category and update the cat attribute.

### 4. Internal links: reducing-an-oversized-hedge.html uses root-relative paths

All other how-to pages use `../`-style relative paths for nav, footer, and inline links. `reducing-an-oversized-hedge.html` uses root-relative paths (`/about.html`, `/services/hedge-trimming.html`, etc.) throughout. On the live web server this is functionally equivalent, but it is inconsistent with the template and will break if the site is ever previewed by opening the files directly in a browser. Recommend aligning to the `../` pattern used site-wide. No broken links in production.

### 5. YouTube video verification: blocked by proxy (carry-over)

YouTube watch and embed URLs cannot be HEAD-checked from this audit environment due to proxy restrictions. Videos referenced (watch links and iframes) are from reputable UK horticultural publishers: RHS, Hopes Grove Nurseries, Heathwood Nurseries, Bunny Guinness, Ashridge Nurseries, STIHL GB, Herons Bonsai, Garden Ninja.
